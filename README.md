# Niwa Cookies – لوحة الإدارة 🍪

موقع خاص لإدارة مشروع Niwa Cookies: الطلبات، المخزون، المصاريف والميزانية، والأرباح.

## المميزات
- **الطلبات**: تسجيل الطلب بالعميل والجوال وموعد التسليم، تتبع الحالة (جديد ← قيد التجهيز ← جاهز ← تم التسليم)، الدفع، ومراسلة العميل واتساب.
- **حساب العروض تلقائي**: إذا طلب العميل 12 حبة بيحسبها بوكس 8 + بوكس 4 بأرخص سعر.
- **المخزون**: كم المتوفر من كل صنف وحجم، ينقص تلقائي مع كل طلب، ويرجع إذا انلغى الطلب.
- **تنبيهات**: لما صنف يقارب يخلص (الحد تختاره أنت لكل صنف) يطلع تنبيه وإشعار.
- **دفعات الإنتاج**: سجّل "سويت دفعة" وتنضاف الكمية للمخزون مع سجل.
- **الميزانية**: المصاريف بالتصنيفات، ميزانية شهرية، وصافي الربح لكل شهر.
- **نسخ احتياطي**: ملف واحد تحفظه أو ترسله لنفسك، وتستورده في أي جهاز.
- يشتغل بدون إنترنت ويتثبّت على الجوال كأنه تطبيق.

## أين تُحفظ البيانات؟
داخل المتصفح في نفس الجهاز فقط (ما تنرفع لأي مكان). الكود على GitHub ما فيه أي بيانات خاصة.
لذلك **سوّ نسخة احتياطية بشكل دوري** من صفحة الإعدادات.
